What BAA knows, and what you can do about it

This page describes, in plain language, exactly what this build actually collects, why, who can reach it, and gives you real controls over it. Nothing here is a generic privacy-policy template — every line below is read from or acts on the real data this app stores on this device.

🔒
Honest security notice: this build now has a PostgreSQL-backed authentication and learner-data layer for selected modules, while some legacy and preference data remains browser-local. Browser-local data is inspectable by anyone with devtools access to this device, so local storage must not be treated as a production security boundary. This is not a claim of "production secure," "fully encrypted," or compliance with any specific law (COPPA/GDPR/FERPA/etc.) — a real compliance posture needs real backend infrastructure this build does not have.

Human oversight & explainability

Module 38/59 — how this actually works today: AI evaluation scores, Learning Intelligence states, and Planner tasks each carry a real, evidence-based explanation (see the "Why?" text already shown in your Learning Profile and Planner) — built from your actual assessment evidence, never a placeholder like "AI recommends this." Where there isn't enough evidence, BAA says "not enough evidence yet" instead of guessing.

A human always has the final say. Any AI evaluation flagged low-confidence goes to a teacher review queue before it's final, and you can request re-evaluation of any graded question below — a teacher's decision always overrides the AI's, and the AI's original evaluation is never deleted, only kept alongside the human decision.

Not yet built in this codebase (so not claimed here): AI-driven career recommendations and "AI Guardian" alerts don't exist yet as features — there is nothing to explain until those are actually implemented in a later section.

Request re-evaluation of a graded answer

If something on a recent assessment looks wrong, you can ask for a real human teacher to look at it — this reuses the same review system Section B already built, it does not create a second one.

Healthy learning pace

BAA optimizes for healthy learning, not maximum time-on-app. A gentle, dismissible break suggestion can appear during long sessions — never a lockout, never guilt-worded, never comparing you to anyone else.
