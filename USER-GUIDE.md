# 4. 📝 ASSESSMENTS

When taking an assessment:

1. Open the assessment.
2. Read each question carefully.
3. Enter your answer.
4. Submit when finished.
5. The system records the available learning evidence.
6. Use the resulting feedback to decide what to study next.

### Important

BAA should not be treated as a machine that automatically knows whether a student has mastered something.

It uses **evidence**.

More useful evidence generally comes from:

- repeated practice
- assessments
- revision
- correct/incorrect responses
- learning history
- comparable measurements over time

---

# 5. 🧠 AI LEARNING INTELLIGENCE

BAA's intelligence features are designed to help answer questions such as:

- What should I study next?
- Which concept needs revision?
- Am I improving?
- What kind of practice should I do?
- Should I revise or move forward?
- What evidence supports this recommendation?

### Evidence principle

If the system does not have enough evidence, it should say so.

It should **not invent a score or pretend certainty**.

---

# 6. 🛤️ LEARNING PATHS

Learning paths organize available learning evidence into a sequence.

A typical cycle is:

**Learn → Practice → Assess → Review → Revise → Reassess → Progress**

If evidence shows that a concept needs revision, the system can direct the student back toward that area.

If evidence supports stronger performance, extension work can be used.

# 41. 🛠️ IF A PAGE DOES NOT OPEN

Check these first:

### A. Did you extract the ZIP?
Do not run the HTML file while it is still inside a compressed ZIP.

### B. Is the complete folder present?
BAA pages depend on JavaScript files and other project files.

### C. Are you using a modern browser?
Chrome, Edge, Firefox or another modern browser is recommended.

### D. Are local browser restrictions affecting a feature?
Some browser features behave differently when an HTML file is opened directly from the filesystem.

### E. Is the feature an external integration?
ERP, live scholarship data, mentor services and similar features require their actual service connection.

# 46. ⭐ GOLDEN RULES FOR USING BAA

### 1. Evidence before certainty
If BAA does not have enough evidence, it should say so.

### 2. AI assists; humans decide
Especially for important student/institution decisions.

### 3. Never invent live information

### 4. Protect student dignity
No shame-based learning.

### 5. Student agency matters
The student should understand and participate in the learning process.

### 6. Safety comes before features
A feature should not be made "complete" by pretending unsupported security or infrastructure exists.
